This project is a web based terminal meant to be used as a boilerplate or starting point for other projects for everyone. As of now the program can run a number of commands such as "ls" "ls -a" "pwd" "cat" "cd" and the custom
"unlock" meant for files that should remain inaccessible until the correct password is guessed by the user. This project is mostly made of Javascript and uses a fragment of CSS and Html for the design to be nice and on theme.
It was made step by step, starting with the filesystem and commands and slowly building onto it and revising where needed. Issues were mostly lacking the proper integration with the html, and locking and unlocking the files.

How to run it:
Open it up on the website
start typing in commands!!

Commands work the same way linux does:
- ls -- lists files in the current directory
- ls -a  -- Same as ls but shows hidden files
- cat [filename] -- reads content of file
- unlock [filename] -- unlocks any locked file, or one with permissions denied
- pwd -- prints the current directory
- cd [directory] -- moves the user into the folder or directory
- whoami -- prints the current user
- clear -- removes all the prior texts from the screen
- uname -- prints OS information


Ai was minimally used to help me troubleshoot the locking and unlocking, as well as helping me with the html and css creation.
